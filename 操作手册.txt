三、前台：客人怎么预约（对着客人演示）
════════════════════════════════

1. 打开繁中或日文首页。第一次会先选语言，点「繁體中文」或「日本語」。
2. 往下看套餐卡片（黄昏湾岸 45 分 / 难波 60 分 / 通天阁 90 分 / 夜间霓虹 90 分 / 大阪城 120 分）。
3. 点「立即预约」或底部「预约」，进入预约页。
4. 先用 ＋ － 选人数。一个套餐最多 4 人（4 台车）。超过要拆成连续时段，后台手工建第二单。
5. 点日历上的日期：
     正常亮度     = 可以约
     右上角绿点   = 当天已有确认出团，客人可以跟团
     灰色点不了   = 已过、休业、满员
6. 弹出时段：10:00 / 11:30 / 13:00 / 14:30 / 16:00 / 17:30 / 19:00。
     「已满」点不了。选一档，点「确认时间」。
7. 点「继续」，填主预约人（姓名、邮箱、电话、证件等）。
8. 可勾加项：GoPro、赛车服升级、跟拍。套餐已含的「基础保险」不用再付。
9. 到付款页。卡 / 微信 / 支付宝是测试开关，演示到这里即可，不必真付。

日历大约可约今天起 60 天。灰色休业日是演示用的（台风、包场、保养），不是店里真实放假。
页脚地址、电话、营业时间 10:00～21:00 来自后台「门店 / 全站」。

五、每个功能怎么操作

————————————————
5.1 仪表盘
————————————————
用来干什么：早上打开看今天几单、有没有待确认、车还剩多少。

怎么点：
  1. 左侧点「仪表盘」。
  2. 上看四块：今日订单、今日营收、待确认、空余车位。
  3. 中间「分店」卡片：难波是营业中。点一张卡片会切到那家店的数据。
  4. 「今日订单时间线」点某一条，弹出订单详情，可改状态。
  5. 底下快捷：新建订单 / 调整库存 / 查看报表 / 管理员工。

怎么判断忙：空余车位少、待确认不是 0，就要进订单列表处理。


————————————————
5.2 订单列表（预约管理 → 订单列表）
————————————————
用来干什么：找单、确认、改人数时间、手工补单、取消。

怎么打开一张单：
  1. 预约管理 → 订单列表。
  2. 上方可搜：订单号、客人姓名、套餐名。
  3. 可筛日期、状态（待确认 / 已确认 / 已完成 / 已取消）、渠道（官网、Klook、微信等）。
  4. 点「详情」或点订单号，打开弹窗。

确认一单（客人付过或店里口头确认）：
  1. 打开详情，或在列表里直接点状态下拉。
  2. 改成「已确认」，保存。
  3. 去前台预约日历：那天右上角会出现绿点（已有确认出团）。

改时间 / 人数 / 套餐：
  1. 详情里点「编辑」。
  2. 改日期、时段、人数、套餐、加项、电话、备注。
  3. 保存。库存会按新人数重算。若该时段车不够，保存时会提示，换一档再存。

手工补一单（电话 / WhatsApp / 现场定的）：
  1. 点「添加订单」。
  2. 填客人、套餐、日期、时段、人数（男/女）、渠道、是否已付。
  3. 保存。这单会出现在日历和库存格子里。

取消 / 退款（演示）：
  1. 详情点「退款」或把状态改成「已取消」。
  2. 系统只改状态，不会真打钱给客人。
  3. 前台该时段会腾出位置。

订单号样子：FK-年月日-序号，例如 FK-261017-201。SK / UM 开头是预留分店的旧演示单，可忽略。


————————————————
5.3 日历（预约管理 → 日历）
————————————————
用来干什么：看今后哪天已经有出团，点一天看名单。

怎么点：
  1. 预约管理 → 日历。
  2. 先确认左上店铺是「难波本店」（全店合计时请先选一门店，三处才对齐）。
  3. 切「月 / 周 / 日」。手机竖屏一次大约 3 天，横过来看一周。
  4. 点某个日期：下方列出当天订单。
  5. 点色块：打开那一单详情。
  6. 斜纹格子 = 锁定或休业，不能再约。

颜色大致：绿较少单，橙较多，深红很满。以点开后的名单为准。


————————————————
5.4 库存管理
————————————————
用来干什么：看每个出发时段还剩几台客人车；某天不营业或某几小时锁掉。

怎么看：
  1. 左侧「库存管理」。
  2. 表格：横轴是日期，纵轴是时段（与前台同一套 10:00–19:00）。
  3. 点一个格子：看当天该时段订了谁、还剩几位。
  4. 可从格子「建单」，会带到订单表单并带上日期时段。

某天全店不营业（台风、包场、保养）：
  1. 库存页找到「特殊日期」。
  2. 填日期，原因写成「台风休业」等。
  3. 类型选「全天休业」，保存。
  4. 打开前台预约页，那天应变灰，点不了。

某天加场（只做标记，方便店里自己看）：
  1. 特殊日期 → 类型选「加开」，写原因，保存。
  2. 前台不一定多出新时段；出发档仍是那 7 个整点。加开是店内备忘。

锁几个时段（车坏了、只开下午）：
  1. 在库存格子上点选连续时段（可拖）。
  2. 选「设为维修」或批量「全部休息」。
  3. 前台对应档会变「已满」或当天变灰。
  4. 要恢复：再选中 →「恢复可订」或「全部营业」。

「一键清空今日库存」会把当天标满，客人当天约不了。演示时慎点。
「恢复默认库存」按车辆状态和现有订单重算当天。


————————————————
5.5 车辆管理
————————————————
用来干什么：10 台车谁能上路。标成维修 / 停驶后，当天库存会少车。

怎么点：
  1. 左侧「车辆管理」。
  2. 点一台车，改状态：可用 / 维修 / 停驶。
  3. 保存。
  4. 回库存页，当天可接人数应变少。

不要把演示车当成真实车架号。正式上线再按店里实车改。


————————————————
5.6 套餐管理
————————————————
用来干什么：改前台套餐名、价格、时长、哪些加项已含。

怎么改价格或名字：
  1. 左侧「套餐管理」。
  2. 点一张套餐，打开编辑。
  3. 可改中 / 英 / 日 / 韩名称、价格（日元、含税）、时长、公里、简介。
  4. 下面附加项：勾选 = 客人可加购。打开「内置」= 套餐价已含，前台写「已含」，不再收费。
  5. 保存。新开前台预约页应看到新价、新名字。

一个套餐最多 4 人，和前台 ＋ － 上限一致。不要改成超过 4，除非店里确认可以一次出更多车。

演示价（含税）：
  黄昏湾岸 45 分    ¥5,000
  难波 60 分        ¥12,800
  通天阁 90 分      ¥15,800
  夜间霓虹 90 分    ¥15,000
  大阪城 120 分     ¥18,800

加项演示价：GoPro ¥2,500 / 车，赛车服升级 ¥1,000 / 人，跟拍 ¥3,000 / 组，基础保险 ¥500 / 人（多数套餐已含）。


————————————————
5.7 内容管理 · 视频
————————————————
用来干什么：首页和「现场画面」播什么。

怎么点：
  1. 内容管理 → 视频管理。
  2. 每个卡片是一个位置（首页主视觉、展示组 1–4 等）。
  3. 可贴 YouTube 链接，或上传本机 mp4 / webm（约 12MB 以内）。
  4. 上传的文件只在这台电脑浏览器里，换电脑要重新传。
  5. 保存后刷新前台首页往下看视频区。


————————————————
5.8 内容管理 · 用户评价
————————————————
用来干什么：首页三则评价的姓名、平台、正文、头像。

怎么点：
  1. 内容管理 → 用户评价。
  2. 点一条，改姓名、平台（Google / Klook 等）、外链、各语言正文、照片。
  3. 关掉「上架」则前台不显示这条。
  4. 保存，刷新首页「用户评价」。


————————————————
5.9 内容管理 · FAQ
————————————————
用来干什么：首页折叠问题和独立 FAQ 页。

怎么点：
  1. 内容管理 → FAQ。
  2. 每条可改问、答（可分语言）。
  3. 勾「首页」：首页常见问题区会显示。
  4. 勾「上架」：FAQ 整页会显示。只上架不勾首页 = 只在 FAQ 页出现。
  5. 驾照、集合、下雨、人数（最多 4 台）都在这里改。


————————————————
5.10 内容管理 · 新闻报道
————————————————
用来干什么：首页新闻 / 媒体条。最多显示 3 条上架。

怎么点：内容管理 → 新闻报道 → 改标题、来源、图、上架 → 保存 → 刷新首页。


————————————————
5.11 内容管理 · 集合地点
————————————————
用来干什么：前台页脚、Access、预约页地图用的地址。

怎么点：
  1. 内容管理 → 集合地点。
  2. 填各语言地址。日文请写完整门牌，例如：
     〒542-0072 大阪府大阪市中央区高津2丁目4-21 おおきに道頓堀ビル
  3. 填车站、步行（难波站步行约 5 分）、地图短链。
  4. 保存。刷新前台页脚，点地址应打开同一栋楼的地图。

不要只写「难波周边」。客人打车需要门牌。

5.12 员工管理
————————————————
用来干什么：加店员、改他是超管 / 店长 / 店员。

怎么点：
  1. 左侧「员工管理」（店长以上）。
  2. 添加：邮箱、显示名、角色、绑定哪家店。
  3. 编辑里可单独开关他能进哪些页。
  4. 演示登录仍是上面三个邮箱，密码随意。正式上线才会变成真密码。

5.13 推广代理
————————————————
用来干什么：看推广员名单、推广链接、抽成（演示数字）。

怎么点：推广代理 → 点一个人看详情和抽成 → 可改姓名电话。
渠道抽成会进报表「门店实收」的扣除，前台客人看不到这一页。

5.14 财务报表
————————————————
营收报表：看趋势、各套餐卖了多少。数字来自当前浏览器里的订单，含演示单。
数据分析：本周 vs 上周、本月 vs 上月、渠道、性别、国籍、热门时段。

不要用这些数字报给会计。正式上线并接真订单后再当业绩。

5.15 权限配置（仅超管）
————————————————
用来干什么：店长默认能进哪些菜单、店员默认能进哪些。

怎么点：权限配置 → 勾/去掉某角色的页面 → 保存。
某个员工还要少一点权限：去员工管理里单独改，不必改角色默认。

5.16 系统设置 · 支付配置
————————————————
用来干什么：预约最后一步出现哪些支付按钮。

怎么点：
  1. 系统设置 → 支付配置。
  2. 打开或关掉 Stripe / 微信 / 支付宝 / PayPay 等。
  3. 保存。去前台走到付款页，只应看到打开的方式。

现在只有测试通道。不要在这里填正式银行卡或正式 Stripe 密钥。

5.17 系统设置 · 渠道设置
————————————————
用来干什么：后台录单时的渠道名单（官网、Klook、携程…）和 OTA 抽成比例。

怎么点：渠道设置 → 改名称或抽成 → 保存。
前台不展示渠道。只影响后台下拉和报表实收。


————————————————
5.18 系统设置 · 预约开关
————————————————
用来干什么：官网上还提供哪些联系方式。

怎么点：
  1. 系统设置 → 预约开关设置。
  2. 可关「在线填写预约」：首页预约按钮会受影响。
  3. WhatsApp / 电话 / 邮件 / LINE：关掉就不在前台出现。
  4. 链接必须是完整店铺地址，例如 https://wa.me/81开头的手机号。
     不要填 instagram.com 官网首页，也不要填座机的 wa.me（收不到）。
  5. 没有真号就关掉对应开关，只留电话 tel: 和邮件。

5.19 系统设置 · 门店管理
————————————————
用来干什么：难波本店的电话、完整地址、营业时间、地图。会同步到前台页脚。

怎么点：
  1. 系统设置 → 门店管理 → 点难波本店。
  2. 电话建议：+81 6-7771-0100（演示号，问店后改成真号）。
  3. 地址用完整日文门牌。营业时间 10:00 – 21:00。
  4. 地图链接与「集合地点」用同一条短链。
  5. 保存，刷新前台页脚。

心斋桥 / 梅田是预留，不要改成「营业中」，也不要往这两家录正式单。

怎么点：邮件设置 → 选模板类型和语言 → 改正文 → 保存。
演示环境发出去的邮件可能到不了客人邮箱，以屏幕提示为准。

5.22 系统设置 · 侧栏按钮
————————————————
用来干什么：首页右侧「关注我们」以及手机「社媒」弹出里有哪些按钮。

  3. 打开的必须贴店铺主页完整链接，不能只贴 instagram.com。
  4. 保存，刷新首页右侧或手机「社媒」。

没有店铺账号就全部关掉，避免客人点进平台首页。

5.24 全站配置
————————————————
用来干什么：店名、Logo、页脚电话 / 邮箱 / 营业时间、页脚一排社媒图标。

怎么点：
  1. 左侧最下「全站配置」。
  2. 改品牌名、上传 Logo（存在本机浏览器）。
  3. 电话、邮箱、营业时间与门店保持一致。
  4. 页脚 Instagram / YouTube / X / Facebook / TikTok / LINE：有真链接再填，否则留空。
  5. 保存，刷新任意语言首页页脚。


════════════════════════════════
六、每天开店可以照着做
════════════════════════════════

早上
  1. 超管登录仪表盘，看待确认是不是 0。
  2. 打开日历，看今天、明天各有几单。
  3. 有坏车：车辆管理标维修，再看库存格子是否已减少。

来了电话 / 消息
  1. 先在订单列表搜姓名或电话，避免重复建单。
  2. 没有这单：添加订单，渠道选「线下」或「WhatsApp」。
  3. 客人已定：状态改「已确认」。

某天不能跑
  1. 库存 → 特殊日期 → 全天休业。
  2. 自己用手机打开前台预约页，确认那天是灰的。

改价
  1. 套餐管理改日元含税价。
  2. 前台四语首页和预约页都应是同一套数字。差 ¥1 也不要上。

下班
  1. 把今天已跑完的单改成「已完成」。
  2. 不要关浏览器的「清除数据」，否则明天演示改动会丢。


════════════════════════════════
七、对不上时先查这里
════════════════════════════════

前台日历全灰
  看是不是日期已过、人数加到 4 人后该日车不够、或特殊日期休业。

改了价前台没变
  用同一浏览器硬刷新。不要开第二个隐身窗。清缓存会丢你改过的价。

社媒按钮点进 Instagram 官网
  侧栏或全站里填了平台首页。改成真店铺链接，或把开关关掉。

日文页没有门牌
  集合地点和门店的日文地址改成完整 〒 门牌，保存后刷新 /ja/。

换了手机后台是空的
  正常。数据在原来那台电脑的浏览器。不要当丢失客人。

付款失败 / 一直转圈
  演示支付本来就不稳定。培训走到付款页即可，不必真付。


════════════════════════════════
八、不要做的事
════════════════════════════════

· 不要把演示订单、演示营收报给店主当真实业绩。
· 不要在支付页或设置里填正式银行卡、正式 Stripe 密钥。
· 不要用微信里 9 月那份 zip 覆盖这个网站（那是旧包）。
· 不要同时开两个窗口改同一项，后保存的会覆盖先保存的。
· 清缓存前，如果改过演示数据又还要留着，先别清。
· 心斋桥 / 梅田不要标营业中。
