这个文件夹怎么看：

打开网站.html    双击看网站（前台 / 后台 / 三套外观 / 酸街配色都在这一页）

src/styles       样式源文件（按前台 / 后台、再按颜色风格拆开）
  front/         前台：shared 共通、neon 霓虹、acid 酸街、oni 鬼街
  admin/         后台：操作台、库存表

src              其余源码（改页面进这里）
public           图片和视频
out              生成好的网页（npm run build 出来的，不要手改页面）
  styles/        和源码对应的可读样式副本（前台按风格、后台单独）
notes            备忘
scripts          构建脚本
supabase         数据库

node_modules、.next、以及各种 json / ts 配置
                 给电脑读的，一般不用点
